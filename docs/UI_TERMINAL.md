# 第一轮产品化：私人投研终端

日期：2026-10-29，北京时间。范围仅为呈现与读取时机；数据库结构、Supabase、认证/权限、CA、已验证provider、AI调用实现与研究规则均未修改。未连接生产数据库，也未向生产写入测试夹具。

## 界面与结构

- `alphalab/ui/__init__.py`：应用外壳和五入口；原生横向radio作为导航，当前页深色下划线，键盘焦点可见。桌面品牌在左、导航在右；手机上下分行，五个入口都在视口内。退出移至“我的 → 账户”。管理员入口仍在“我的研究空间”内，权限校验保留。
- `components.py`：品牌、`data_meta()`、轻量空状态、指标网格、图表样式与既有AI按钮。所有动态HTML转义，图表复用CSS tokens，不增加JS或第三方导航依赖。
- `login.py`：440px以内的登录区，指定标题/副标题，注册改为次级展开入口；邀请和手机号说明置底。
- `home.py`：市场概览 → 我的研究（现有自选/报告）→ 最多3条政策观察。无指数时安静空状态；快照无数据时只显示一行。保留手动市场简报入口。
- `stock.py`：搜索表单、公司Header、来源/更新时间与小型价格缺失标签。概览/走势/财务/主营/AI研究分别执行。四项公司字段、六项财务网格、主营表格，走势默认显示已有数据中的近三年；未复权、报表期/公告日区别与分类不可叠加等口径保留在对应展开区。
- `account.py` / `admin.py` / `discovery.py`：迁移既有个人、管理员和行业/筛选页面，统一组件与按钮层级。风险提示和管理能力保留；没有增加金融功能或权限。
- `assets/styles.css`：暖白、石墨文字、深蓝强调、少量琥珀状态、红涨绿跌；颜色、圆角和内容宽度集中为tokens。原生Streamlit主题配置与相同tokens对应，内容最大宽度1220px。

## 读取时机与性能

新增`ui/reads.py`是UI的只读适配层；原`MarketData`与provider文件不变。

1. 首页默认只读已有公共缓存。搜索复用原有`search()`匹配逻辑，但其名单读取强制`cached_only=True`，不因缓存缺失自动访问名单接口。管理员仍通过既有“基础证券名单”入口明确刷新。
2. 个股日线、财务、主营默认只读已有持久化记录，没有记录时提示“待更新”。只有“更新研究数据”才调用原有三个接口，并行请求、独立保留旧缓存。只在用户点击时调用AI，参数结构、用途与原有幂等逻辑保留。
3. 日线读取最新已保存的默认范围记录，日期跨天不因新的end日期而误判没有旧缓存；不把旧行情标为当日实时行情。
4. Streamlit 1.50原生`st.tabs`会执行所有标签。研究区采用原生radio呈现页签外观，按条件只执行选中区。概览仅需基础资料、核心财务和最新日线日期；不读取主营，不生成图表。图表DataFrame只在走势打开时转换。
5. 公共读取结果与图表转换在当前浏览器session内保留最多30秒、48个条目；显式更新、管理员刷新名单或清除缓存会使该session视图失效。其他session最多30秒后读到新值；不存在后台自动抓取。私人查询和当前会话/角色验证不做共享缓存，每次rerun仍验证授权。
6. 缺少某块研究数据不阻断搜索/Header/其他分页；来源异常不会直接显示在普通页面。历史缓存以小标签提示，模拟/回测等安全或研究风险警告仍保留。

Streamlit依然会整页rerun，不能等同于SPA局部路由。图表第一次加载的前端资源、平台休眠唤醒、真实Supabase延迟和上游手动更新耗时不由本轮UI优化消除。

## 合并后生产验收：重点截图这五处

无需修改Secrets、迁移数据库、初始化管理员或清除现有公共缓存。合并后在Community Cloud Reboot app。

1. **登录页**：桌面居中窄表单；390/430px无溢出，注册为次级展开项。
2. **首页**：市场概览、我的研究、最多3条政策；缺源无大面积警告，无自动抓取等待。更新按钮仍能手动更新原有指数/政策链，不承诺未恢复源已恢复。
3. **贵州茅台个股概览**：代码600519与名称搜索，Header/自选按钮/四项字段；无实时价格时只有小标签。已有缓存立即展示，无缓存点击“更新研究数据”后再看，数据必须来自生产真实源。
4. **贵州茅台财务页签**：六项紧凑指标，单位/报表期以原始数据为准；同时切走势、主营、AI研究，确认不会同时渲染其他重模块。走势显示不复权与实际数据日期，AI只点击后生成。
5. **我的页面**：持仓/自选/研究历史保持可用，“账户”中退出登录；管理员后台和名单刷新仍在“我的研究空间”，普通用户不出现后台。

每处建议各截1440、390、430px。首次休眠唤醒与再次打开分开记录实际耗时。不要把真实Secrets、完整手机号、数据库配置或私人研究内容截图发送到公开渠道。
