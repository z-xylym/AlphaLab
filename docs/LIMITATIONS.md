# 当前范围与限制

以下限制是实际交付边界，不应把测试通过解释成全部V1最终验收通过。

## 已实现

邀请账户、Argon2id、会话期限/吊销、数据库登录限流、服务端owner隔离、管理员用户启停和个人额度、平台配置预算与Token估价；五入口手机界面；真实源适配与PostgreSQL公共缓存；公司资料/主营/财务摘要/历史图/名称和代码搜索；研究和聊天及按相关性有限检索的长期记忆；关注、自选和报告删除；手动持仓增改删与集中度；观察名单规则与后续收益；原子模拟账本；可保存输入/参数/hash的实验均线回测；初始化SQL、幂等管理CLI、测试和部署文档。

## 受限实现

- 筛选为控制公开接口压力，先按代码排序取最多30只流动性候选再核对上市时间和财务，**不是完整全市场扫描**，结果可为空；稳健质量缺少可靠指标不入选，不会补零。动量只用快照涨幅，是实验观察规则。
- 行业为东方财富供应商口径，主题与行业分开；未实现申万/中信历史分类映射、完整行业盈利模式数据库。
- 行情快照可能不提供有效交易日期，明确显示“抓取时间不等于交易时间”；不能称为实时交易终端。指数和个股日线显示最近已发布日期。
- 财务按报表期展示，字段缺失则暂无可靠数据；没有可靠历史公告日数据库，不支持财务因子点时回测。
- 官方政策索引与可识别正文抓取已实现；全文格式不匹配时拒绝分析。行业标题匹配仅作检索，AI的措施/机制/公司关联属于需人工核对的推断，未建立经过人工核验的完整政策知识图谱。发文部门、发布时间和生效状态以原文为准。
- 模拟成交使用最近发布日线收盘价加滑点，100股整数倍，非ST沪深主板；拒绝接近涨跌停及过时价格；T+1按交易日线日期执行。未模拟订单簿、部分成交或盘中报价。
- 回测只提供双均线价格策略（非质量/估值历史选股回测），次日开盘成交，固定成本/印花税/滑点和保守10%限制，样本外独立现金起步。未实现历史税率、ST身份变化、新股无涨跌停阶段、除权分红、所有板块交易制度与退市样本，存在幸存者偏差；明确实验性质。
- 历史名单后续1/5/20日观察在用户打开并点击时计算，不宣称有Community Cloud后台定时作业；快照价格不保证当时能成交。
- 长期记忆使用有限条目关键词排序，不依赖向量库；聊天与记忆可分别删除，没有自动压缩全部对话。
- 无短信验证、MFA、自助找回密码、账号导出；手机号仅登录标识。普通用户不能自助任意注册。
- 浏览器会话不会长期自动登录，页面重载导致WebSocket会话丢失时需要重新登录。
