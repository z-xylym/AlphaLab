# AlphaLab V1.1 产品结构与视觉验收

基线：main 的 0a7d225。仅修改前端路由、组合布局、共享展示组件、样式和相应测试；不更换数据源，不迁移数据库，不改生产配置、AI生成契约、认证或TLS。

## 页面层级

- 首页：三大历史指数固定位置 + 我的自选 + 最近研究 + 官方政策观察。指数缺失只影响自己的卡片。个人区桌面双栏、手机单栏；没有资料时明确缺失。首页不再堆放实时快照和额外市场AI生成入口。
- 市场：将已有市场概览、行业观察、选股观察收纳为二级内容，保留原有功能和缺失数据规则。
- 自选：独立主导航，复用 watchlist_items。名称/代码、缓存价格/涨跌、最近研究状态、查看研究和移出操作均复用已有记录。无快照显示缺失，不发起实时行情请求。分组仅在折叠说明中预留，尚未启用。
- 个股：公司Header、研究状态、更新状态、八项核心指标、概览/走势/财务/主营/AI研究/预警。没有价格不影响财务、主营或研究。概览不重复堆放顶部财务卡片。
- AI研究：独立研究库入口，按当前用户读取已保存报告，支持本地名称/代码检索和阅读。公司页签仍保留生成能力，九章阅读器共享，分隔事实、AI分析和数据缺失，摘要元数据、来源、缺口及输入快照保持可核对。历史通用报告保留原文阅读能力。
- 我的：保留账户、持仓、历史研究与原有工具、管理入口。旧自选入口引导到独立页面，不维护第二套自选列表。

## 视觉规范

冷静深蓝、柔和浅底、白色指标卡、蓝灰说明文字、少量香槟色标题点缀；圆角、细边框和轻阴影统一。主按钮深蓝渐变，次按钮白底浅边框，保持44px触控高度及键盘焦点状态。数据使用表格数字间距；上涨红、下跌绿、平盘/缺失灰。来源、北京时间更新标签和历史缓存标记统一。

字体栈优先 Inter、Noto Sans SC/思源黑体及系统中文字体；不请求外部字体CDN，避免额外网络与首屏阻塞。未安装的字体回退到系统字体。

## 功能预留

预警页签仅显示规划状态，不创建阈值、不监控或发送通知。短期/中期/长期研究框架在折叠区预留，不生成期限观点。继续追问的独立输入/对话区域明确标记“规划中”，输入框禁用，不调用AI、不产生费用。

## 性能、安全及验收

新增导航和阅读不自动刷新资料或调用AI。公共快照只读既有缓存；个股研究使用原 CachedResearch。私有资料仍经过Repository实时身份校验，界面HTML动态内容全部转义。未改变 Secrets 读取、预算、报告指纹或持久化模型。

浏览器检查 scripts/browser_check.py 使用一次性PostgreSQL及明确标识的虚构布局夹具，禁止外部数据调用，不调用真实DeepSeek。检查1440/390/430px：六个导航、首页、自选、市场、研究库九章阅读、个股六页签、预警占位、账户/管理入口；确认无页面水平溢出、主要按钮44px、图表不溢出、导航选中状态及重复打开耗时。截图与结果写入忽略的 test-results/。

完整测试结果以本轮最终命令输出为准；新增AppTest覆盖自选跳转/删除、私有报告隔离、九章阅读、禁用问答输入及市场二级导航。测试结果不代表真实生产数据或预警/问答能力已上线。
